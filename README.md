# 뽀송연구회 스마트 신발장

**Flask를 실행하면 라즈베리파이 없이도 모든 제어 버튼을 시연할 수 있습니다.** 기본은 시연 모드이며 관리자 비밀번호 설정이 필요 없습니다. 웹은 Flask 템플릿으로 제공합니다. 별도 HTML 직접 실행 버전은 없습니다.

## 바로 실행

Python 3.11 이상, 프로젝트 폴더에서:

```sh
python -m pip install -r requirements.txt
python app.py
```

macOS/Linux에서 `python`이 없다면 `python3`를 사용합니다. 시스템 패키지 설치가 제한되어 있으면 먼저 `python3 -m venv .venv` 후 가상환경을 활성화하세요(macOS/Linux: `source .venv/bin/activate`, Windows: `.venv\Scripts\Activate.ps1`).

- 메인 화면: http://127.0.0.1:5000
- **관리자 바로가기: http://127.0.0.1:5000/admin** — 기본 시연 모드에서는 비밀번호 없이 열립니다.
- 폰 접속: 같은 Wi-Fi에서 `http://노트북또는라즈베리파이IP:5000`을 엽니다. 이 메인 주소를 공통 QR 1개에 넣습니다. `localhost`와 `127.0.0.1`은 폰에서 노트북을 가리키지 않습니다.

서버 터미널을 계속 켜두세요. 방화벽의 5000번 포트와 기기 간 통신이 허용되어야 합니다. 위치 기반 날씨는 localhost/HTTPS에서만 위치 기능을 사용할 수 있어 일반 HTTP LAN 주소에서는 위치 권한이 제한될 수 있습니다.

## 버튼 시연

### 가정용

1. 칸을 열고 **문 열기**를 누릅니다. 시연 문 상태가 OPEN으로 바뀝니다.
2. **신발 넣기 (시연)**를 누르면 보관 세션을 자동 생성하고 습도 65%를 입력해 팬이 시작됩니다.
3. **문 닫기**, **팬 정지**, **팬 시작** 버튼으로 상태 변화를 확인합니다.
4. **문 열기 → 신발 꺼내기 (시연) → 문 닫기**로 마무리합니다.

### 공공장소용

1. 관리자 화면에서 PUBLIC을 선택하고 저장합니다. 또는 **공공장소 사용자 화면 미리보기**가 빈 칸 상태에서 PUBLIC 전환과 사용자 화면 이동을 수행합니다.
2. 칸 선택 → 비밀번호 4~32자 설정 → 예약합니다.
3. **문 열기 → 신발 넣기 (시연) → 문 닫기**로 입고합니다.
4. **출고 요청** 또는 **문 열기**를 누르면 출고 요청과 시연 문 열림이 반영됩니다. 이때까지 비밀번호와 세션은 유지됩니다.
5. **신발 꺼내기 (시연)**를 누르면 정상 출고를 확인하고 비밀번호 및 해당 세션의 모든 토큰을 무효화합니다.
6. 관리자 화면에서 해당 칸 **문 닫기**를 누르면 다음 사용자가 이용할 수 있습니다.

입고 전 예약 취소, 비밀번호 재인증, 관리자 로그아웃도 동작합니다. 예약은 10분 미입고 시 다음 API 조회에서 만료되며, 토큰은 30분 만료 후 비밀번호로 재인증할 수 있습니다.

### 관리자

- 칸 상세, 문 열기·닫기, 팬 시작·정지
- 센서 입력 시연: 입고, 문 열림, 반출, 문 닫힘, 문 오류
- 이용 기록 보기·접기, 건조 기록 보기
- 공통 QR 주소 복사 (복사 권한이 없으면 주소 표시)
- **시연 초기화**: 보관 세션을 종료하고 두 칸의 문·팬·센서를 초기화합니다. 기존 기록은 유지됩니다.

모드 변경은 모든 칸이 비고 문이 닫혔을 때 가능합니다. 이용 중이면 시연을 마치거나 시연 초기화를 사용하세요. 출고 요청 없이 반출하면 UNEXPECTED_REMOVAL을 기록하고 세션을 유지합니다. 문 오류에서도 세션을 지우지 않습니다. Mock 입력은 실물 센서 확인이 아닌 시연입니다.

## 팀원 하드웨어 코드 연결

[hardware/README.md](hardware/README.md)에 연결 규격이 있습니다.

1. `hardware/team_driver.example.py`를 **`hardware/team_driver.py`**로 복사합니다.
2. 예제의 5개 함수 안에서 팀원의 기존 센서·서보·팬 함수를 호출합니다.
3. Flask를 재시작합니다. 연결 파일이 있으면 자동으로 그 드라이버를 사용합니다. 웹 버튼이나 API를 수정할 필요 없습니다.

임의의 파일을 넣기만 하면 자동으로 센서 함수명을 추측하는 구조는 아닙니다. **예제의 함수명과 반환값을 맞추면 연결됩니다.** 연결 파일의 오류는 숨기지 않고 시작 오류 또는 화면의 센서·제어 오류로 알립니다.

실제 드라이버를 연결하면 시연 입력과 비밀번호 없는 관리자 접근은 자동으로 꺼집니다. 이때 관리자 비밀번호를 지정하세요.

macOS/Linux:

```sh
export ADMIN_PASSWORD='원하는관리자비밀번호'
python app.py
```

Windows PowerShell:

```powershell
$env:ADMIN_PASSWORD='원하는관리자비밀번호'
python app.py
```

장치 없이 기존 관리자 비밀번호 인증을 테스트하려면 `DEMO_MODE=0` 환경변수도 지정합니다. 기본 시연에서는 위 환경변수 설정 없이 `python app.py`만 실행하면 됩니다.

## 저장·제어 방식

- SQLite `instance/bbosong.db` 자동 생성 및 기존 DB 자동 확장, 재시작 후 기록 유지
- PUBLIC 인증·칸별 권한은 Flask에서 검증. 비밀번호 scrypt 해시와 토큰 SHA-256 해시 저장
- 단일 활성 세션 인덱스와 트랜잭션으로 동시 중복 예약 방지
- 실제 드라이버는 명령 수락과 실제 문 열림을 구분. `read_compartment()`의 관측으로만 개방·반출 확인
- 온습도·팬·문은 시연 모드에서 DB 상태로 작동하며 실제 장치로 전달하지 않음
- 건조 시작·정지 기록. 습도 60% 이상 시작, 50% 이하 정지로 히스테리시스 적용
- 목표 습도에 도달하기 전 수동 팬 정지는 완료로 주장하지 않고 IDLE 기록
- 건조시간 예측값은 데이터가 없어 null 유지
- `DRY_STOP`, `DOOR_ERROR` 이벤트를 기존 Enum에 추가

## 검증

```sh
python -m unittest discover -s tests -v
node --check static/js/script.js
```

테스트는 임시 DB를 사용합니다. 비밀번호·토큰·동시 중복 예약·정상/실패 출고·관리자 제한 외에 비밀번호 없는 시연 관리자, 문·팬·입출고 버튼, 건조 기록, 드라이버 자동 선택과 실제 관측 구분을 검증합니다.
